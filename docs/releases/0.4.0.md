# ModPorter 0.4.0 Developer Preview

ModPorter is a rule-based starting point for developers moving Forge 1.20.1
projects to NeoForge 1.21.1. This release expands the migration rules and the
source-project verification pipeline while keeping generated code available
for human review and focused gameplay testing.

## Engineering Milestone

The recorded strict benchmark covers ConstructionWand, InstantWorldMirror,
HotBath, ShowerCore, Sakura, Twilight Forest, The Aether, Beyond the Veil,
StarMeowCraft, Create, and the Forge-only WorldEdit input. All 11 required
targets passed the strict baseline without failed or skipped targets.

The automated checks cover compilation, dedicated-server startup/shutdown,
project GameTests, client boot, saved-world loading, creative inventory
browsing, item-interface presentation, and evidence-backed runtime log audit.
Individual items' and machines' complete gameplay behavior remains part of
subsequent developer review and targeted testing.

## Changes

- Expanded reusable API, registry, capability, provider, recipe, rendering,
  item-data, resource, and build-system migrations.
- Hardened Create's source-preserving migration and native validation paths.
- Added isolated GameTest worlds, owned-process cleanup, and stronger runtime
  evidence checks.
- Added cross-platform CI and gated developer-preview publishing with checksums.
- Made public builds self-contained, with an optional local private-framework
  preflight for maintainers who explicitly select it.
- Clarified the developer/research purpose, provenance, test coverage, and
  generated-port issue workflow.
- Licensed ModPorter under Apache-2.0 with third-party attribution retained.

## Artifacts and Runtime

This release contains only the ModPorter fat JAR and SHA256SUMS. Converted mod
JARs are published separately, when their original licenses permit it and the
specific packaged candidate has been verified.

The tool requires Java 17+. NeoForge 1.21.1 build/runtime verification requires
Java 21. Build and test entry points also use Python and PowerShell 7.

Migration reports and issues: https://github.com/CrabMods/modporter/issues
